## 1. 회의 핵심 내용 요약

* 기본 퍼즐 플레이 및 스테이지 이동 기능 1차 구현이 완료되었으며, 일부 스마트폰 화면 전환 지연과 광고 시청 후 복귀 시 오류 개선이 필요한 상황입니다.


* 초반 난이도 완화를 위해 1~10단계 난이도 조정안이 논의되었고, 다음 회의에서 설명하기로 했습니다.


* 메인 화면 및 스테이지 선택 화면 디자인 초안이 완료되었으며, 메인 화면의 게임 시작 버튼 수정 시안을 11월 24일까지 공유하기로 했습니다.


* 내부 테스트는 12월 중순경 예상되며, 테스트 전 주요 기능 및 광고 연동 오류 해결이 강조되었고 출시 목표일은 테스트 결과 확인 후 재논의하기로 했습니다.


* 효과음 제작 외주업체의 1차 납품이 11월 18일까지 완료되지 않아 지연 사유와 변경 납품 일정을 확인하기로 했으며, 11월 운영비 지출 내역을 항목별로 구분해 다음 주 경영회의에서 보고할 예정입니다.



---

## 2. 확정된 결정사항

* **최종 UI 디자인 확정 시점:** 수정된 메인 화면 시안을 확인한 후 최종 UI 디자인 확정 여부를 결정하기로 함.


* **출시 목표일 논의 시점:** 내부 테스트 결과를 확인한 후 출시 목표일을 다시 논의하기로 함.


* **효과음 외주업체 조치 결정 시점:** 외주업체의 지연 사유와 변경된 납품 가능 일정 확인 결과를 보고 일정 변경 요청이나 계약상 조치 여부를 결정하기로 함.


* **11월 운영비 지출 내역 구분:** 인건비, 외주비, 소프트웨어 구독료, 일반관리비로 구분하여 다음 주 경영회의에서 보고하기로 함.

## 4. 추가 확인이 필요한 사항

* **퍼즐게임 오류 개선 작업의 정확한 완료일:** 다음 주까지 진행한다고 언급되었으나 정확한 완료일이 정해지지 않았습니다.


* **스테이지 난이도 조정안 제출 날짜:** 다음 회의에서 설명하기로 했으나 구체적인 제출 날짜가 정해지지 않았습니다.


* **최종 UI 디자인 확정 여부:** 11월 24일 공유되는 메인 화면 수정 시안을 확인한 뒤 결정해야 합니다.


* **광고 연동 오류 확인 완료 예정일:** 최현우 개발자가 우선 확인하겠다고 했으나 완료 예정일이 언급되지 않았습니다.


* **내부 테스트용 테스트 시나리오 작성 담당자 및 제출 기한:** 필요성이 제안되었으나 담당자와 기한이 아직 정해지지 않았습니다.


* **출시 목표일:** 내부 테스트 결과를 확인한 후 다시 논의해야 합니다.


* **효과음 외주업체 지연 사유, 변경된 납품 가능 일정 및 후속 조치 여부:** 계약서·이메일 확인 및 업체 연락 후 확인된 내용을 바탕으로 일정 변경 요청이나 계약상 조치 여부를 결정해야 합니다.


* **11월 운영비 지출 내역 보고서 제출 날짜:** 다음 주 경영회의에서 보고할 예정이나 별도 제출 날짜가 정해지지 않았습니다.
