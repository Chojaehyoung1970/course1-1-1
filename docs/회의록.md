# 미니 퍼즐게임 개발 스타트업 주간업무회의 회의록

## 1. 회의 개요

- **회의명:** 11월 3주차 주간 업무회의
- **일시:** 2026년 11월 19일(목) 10:00~11:00
- **장소:** 사내 회의실
- **참석자:** 
  - 김민수 대표
  - 박준호 개발팀장
  - 이서연 게임기획 담당
  - 최현우 클라이언트 개발자
  - 정유진 UI/UX 디자이너
  - 한지훈 경영지원 담당

## 2. 주요 안건

1. 미니 퍼즐게임 개발 진행 상황
2. 게임 주요 기능 및 난이도 조정
3. 디자인 및 UI 개발 일정
4. 테스트 및 출시 준비
5. 외주 및 회사 운영 관련 사항

## 3. 회의 내용

### 안건 1. 미니 퍼즐게임 개발 진행 상황

- 박준호 개발팀장: 기본 퍼즐 플레이 기능과 스테이지 이동 기능은 1차 구현을 완료했다고 보고함.
- 최현우 개발자: 일부 스마트폰에서 게임 실행 시 화면 전환이 느리고, 광고 시청 후 게임으로 돌아올 때 오류가 발생하는 현상이 있다고 설명함.
- 김민수 대표: 신규 기능 추가보다 현재 구현된 기능의 안정성을 먼저 확보하는 것이 좋겠다고 의견을 제시함.
- 박준호 개발팀장: 다음 주까지 오류 현황을 정리하고 개선 작업을 진행하겠다고 말함. 정확한 완료일은 아직 정하지 않음.

### 안건 2. 게임 주요 기능 및 난이도 조정

- 이서연 기획 담당: 현재 스테이지 난이도가 초반부터 다소 높다는 테스트 의견이 있어 1~10단계 난이도 조정을 제안함.
- 김민수 대표: 초반 이용자의 이탈을 줄이는 것이 중요하므로 난이도 조정안을 검토할 필요가 있다고 말함.
- 박준호 개발팀장: 난이도 조정은 기획안이 확정된 후 개발 일정에 반영할 수 있다고 설명함.
- 이서연 기획 담당: 난이도 조정안을 정리해서 다음 회의 때 설명하겠다고 말함. 제출 날짜는 정하지 않음.

### 안건 3. 디자인 및 UI 개발 일정

- 정유진 디자이너: 게임 메인 화면과 스테이지 선택 화면의 디자인 초안을 완료했다고 보고함.
- 최현우 개발자: 디자인이 확정되면 화면 적용 작업을 진행할 수 있다고 설명함.
- 김민수 대표: 메인 화면의 게임 시작 버튼을 더 눈에 띄게 수정해 달라고 요청함.
- 정유진 디자이너: 수정된 메인 화면 시안을 11월 24일까지 공유하겠다고 답변함.
- 최종 UI 디자인 확정 여부는 수정 시안을 확인한 후 결정하기로 함.

### 안건 4. 테스트 및 출시 준비

- 박준호 개발팀장: 현재 개발 속도를 고려하면 12월 중순경 내부 테스트가 가능할 것으로 예상한다고 보고함.
- 김민수 대표: 내부 테스트 전에 최소한 주요 기능과 광고 연동 오류는 해결되어야 한다고 강조함.
- 최현우 개발자: 광고 연동 오류를 우선 확인하겠다고 말했으나 완료 예정일은 언급하지 않음.
- 이서연 기획 담당: 내부 테스트용 테스트 시나리오를 준비할 필요가 있다고 제안함.
- 테스트 시나리오 작성 담당자와 제출 기한은 아직 정해지지 않음.
- 출시 목표일은 내부 테스트 결과를 확인한 후 다시 논의하기로 함.

### 안건 5. 외주 및 회사 운영 관련 사항

- 한지훈 경영지원 담당: 게임 효과음 제작 외주업체의 1차 납품이 당초 일정인 11월 18일까지 완료되지 않았다고 보고함.
- 김민수 대표: 지연 사유와 변경된 납품 가능 일정을 먼저 확인해 달라고 요청함.
- 한지훈 경영지원 담당: 외주 계약서와 기존 이메일을 확인한 후 업체에 연락하겠다고 답변함.
- 외주업체에 대한 일정 변경 요청이나 계약상 조치 여부는 확인 결과를 보고 결정하기로 함.
- 한지훈 경영지원 담당: 11월 운영비 지출 내역을 정리 중이며, 다음 주 경영회의에서 보고할 예정이라고 설명함.
- 김민수 대표: 인건비, 외주비, 소프트웨어 구독료, 일반관리비로 구분해서 정리해 달라고 요청함.
- 보고서 제출 날짜는 별도로 정하지 않음.

  5. 효과음 외주 납품 일정 확인
