# 주간 업무회의 회의록

## 1. 회의 개요

- 회의명: 11월 3주차 주간 업무회의
- 회의 일시: 2026년 11월 18일(수) 오전 10:00~11:00
- 회의 장소: 사내 회의실
- 참석자:
  - 김민수 대표
  - 박준호 개발팀장
  - 이서연 기획담당
  - 최현우 클라이언트 개발자
  - 정유진 디자인 담당
  - 한지훈 경영지원 담당

## 2. 주요 안건

1. 풋볼마에스트로 게임 개발 진행 상황
2. 신규 기능 및 UI 개선
3. 외주 개발 진행 상황
4. 향후 개발 일정 및 업무 분담
5. 회사 운영 및 경영지원 사항

## 3. 회의 내용

### 안건 1. 게임 개발 진행 상황

박준호 개발팀장은 현재 풋볼마에스트로의 주요 기능 개발이 진행 중이며, 선수 관리 및 구단 운영 기능은 기본적인 구현이 완료되었다고 보고했다.

최현우 개발자는 일부 화면에서 데이터 로딩 속도가 느린 문제가 있다고 설명했다. 특히 선수 정보 화면과 경기 결과 화면에서 개선이 필요하다고 말했다.

김민수 대표는 게임의 전체적인 완성도도 중요하지만 사용자가 실제로 플레이할 때 불편함이 없도록 주요 화면의 안정성을 우선 확보해 달라고 요청했다.

### 안건 2. 신규 기능 및 UI 개선

이서연 기획담당은 선수 성장 시스템의 일부 기능을 추가할 필요가 있다고 제안했다.

정유진 디자인 담당은 현재 UI 디자인에서 일부 버튼의 위치와 색상을 조정하면 사용자 편의성이 높아질 것이라고 설명했다.

회의 결과, 선수 성장 시스템의 신규 기능은 기획안을 먼저 검토한 후 개발 여부를 확정하기로 했다.

UI 수정은 우선순위를 정해 진행하기로 했으며, 정유진 담당자가 11월 25일까지 수정 시안을 작성하기로 했다.

### 안건 3. 외주 개발 진행 상황

박준호 개발팀장은 외주 개발업체의 작업 진행 상황을 확인한 결과, 일부 기능의 개발 일정이 당초 계획보다 늦어지고 있다고 보고했다.

김민수 대표는 외주 개발업체에 지연 사유와 수정된 납품 일정을 확인할 필요가 있다고 말했다.

한지훈 경영지원 담당자는 외주 계약서와 기존 작업 일정을 확인한 후 필요한 사항을 정리하겠다고 답했다.

외주업체에 공식적으로 일정 변경을 요청할지는 지연 사유를 확인한 다음 결정하기로 했다.

### 안건 4. 향후 개발 일정 및 업무 분담

김민수 대표는 12월 초까지 주요 기능 개발을 마무리하고 내부 테스트를 시작하는 것을 목표로 제시했다.

박준호 개발팀장은 현재 개발 인력과 작업량을 고려하면 세부 일정 조정이 필요하다고 설명했다.

최현우 개발자는 데이터 로딩 속도 개선 작업을 우선 진행하겠다고 말했다.

다만 해당 작업의 구체적인 완료 기한은 정하지 않았다.

이서연 기획담당은 선수 성장 시스템 기획안을 정리해 다음 회의에서 다시 논의하자고 제안했다. 기획안 제출 담당자와 날짜는 명확하게 확정되지 않았다.

### 안건 5. 회사 운영 및 경영지원 사항

한지훈 경영지원 담당자는 11월 월간 비용 집행 현황을 정리하고 있으며, 다음 주 경영회의에서 보고할 예정이라고 설명했다.

김민수 대표는 월별 인건비, 외주비, 일반관리비를 구분해 확인할 수 있도록 자료를 정리해 달라고 요청했다.

정확한 제출 날짜는 별도로 정하지 않았다.

또한 12월 초에 전 직원이 참여하는 개발 진행 상황 공유회의를 개최하는 방안이 제안되었다.

회의 개최 여부와 구체적인 일정은 추후 확정하기로 했다.

## 4. 회의 중 주요 결정 사항

1. 게임의 주요 화면 안정성 확보를 우선 추진한다.
2. UI 수정 시안은 정유진 담당자가 11월 25일까지 작성한다.
3. 외주 개발 지연 사유와 수정 납품 일정을 먼저 확인한 후 대응 방안을 결정한다.
4. 데이터 로딩 속도 개선 작업을 우선 진행한다.
5. 월별 비용 집행 현황은 인건비, 외주비, 일반관리비로 구분해 정리한다.
